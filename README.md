# C++ 小对象内存池easyVersion v0.1 （ExpandVersion在myMemPool_V2）

## 项目介绍

实现一个用于小对象分配与回收的内存池，减少重复申请系统内存。

## 实现方式

- 64 个内存池，槽大小为 8、16、……、512 字节。
- 每次申请 4096 字节的内存块。
- 使用空闲链表回收和复用内存槽。
- 使用互斥锁保护并发分配与回收。
- 超过 512 字节的对象使用普通动态内存分配。

## 编译运行

1. 使用 Visual Studio 打开解决方案。
2. 将 C++ 语言标准设置为 C++17。
3. 编译并运行测试程序。

## 文件说明

- MemPool.h：内存池实现。
- MemPool.cpp：测试程序。

## 使用注意

- 使用前完成内存池初始化。
- 对象通过配套接口创建和销毁。
- 所有工作线程结束后，再销毁内存池。
